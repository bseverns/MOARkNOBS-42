Bridge command center

Default path: choose device, choose host recipe, start the bridge, open the App, then download a snapshot if something fails. Raw serial and WebSocket debugging still exist, but they stay in Advanced where they belong.

  1. Choose devicePick the detected serial port.

Local-only by default. Keep this console, `/api/*`, `/ws`, OSC, and MIDI command lanes on a trusted host/network unless you have deliberate network protection.
