# Security Policy

## Reporting

Please report suspected vulnerabilities privately to [severns3@gmail.com](mailto:severns3@gmail.com). Include the affected version or commit, reproduction steps, and the smallest non-sensitive evidence needed to understand the issue.

Do not open a public issue for an unpatched vulnerability. Do not send credentials, private device data, signing material, or other secrets; redact them before sharing logs or screenshots.

Ordinary bugs and support questions belong in [GitHub Issues](https://github.com/bseverns/MOARkNOBS-42/issues).

## Scope

Security fixes target the current `main` branch and latest published release. Older prototype snapshots may not receive fixes. This project does not currently promise a response or remediation time.
