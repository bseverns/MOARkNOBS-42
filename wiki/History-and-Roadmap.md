- 2024: initial firmware architecture and module foundations.
- Early 2025: hardware layout iterations and repository reorganization.
- Mid 2025: firmware stabilization, test harness growth, first release cadence.

- `v0.1.0` (August 2025): first public release.
- `v0.2.0` (October 2025): diagnostic + release discipline improvements.
- Current track: onboarding, reliability, and release packaging toward stable v1.x workflows.
