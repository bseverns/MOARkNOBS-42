# Archived Wiki Source Pack

> in [`docs/`](../docs/index.md), the root [`README.md`](../README.md), and the component READMEs.

The files in this directory are retained as historical source material so existing GitHub Wiki links do not disappear.
They may describe older workflows or support boundaries and must not be used to settle current behavior.

## Maintenance policy

- Do not add new guidance to `wiki/`.
- Fix a wiki page only when needed to prevent a dangerous or materially misleading stale instruction.
- Move any still-unique, current content into `docs/` before updating it.
- Do not publish this directory as a replacement for the maintained documentation site.

Existing pages remain snapshots. Their `Canonical source` declarations point readers toward the maintained contract or
guide that supersedes them.
