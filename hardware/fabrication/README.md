# MOARkNOBS-42 Fabrication Artifacts

This directory is the canonical location for verified PCB manufacturing documents, primarily **Gerber / NC Drill packages** needed to duplicate the physical board cleanly.

## Currently Omitted

At present, **no orderable fabrication packages are enclosed**.
The repository intentionally delays supplying push-button manufacturing `.zip` drops until the experimental PCB footprint layouts are physically signed off and validated as functionally perfect in the beta loop constraints. Consequently, the distributed hardware asset constitutes a **reference bundle**—ideal for code review, schematics tracing, and planning—instead of a factory-ready "fabrication zip."

When Phase 5 concludes and verified revisions are confirmed, standardized Gerbers will inhabit this folder.
