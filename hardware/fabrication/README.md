# MOARkNOBS-42 Fabrication Artifacts

This directory is the canonical location for verified PCB manufacturing documents when they exist, primarily **Gerber / NC Drill packages** needed to duplicate the physical board cleanly.

## Currently Omitted

At present, **no orderable fabrication packages are enclosed**.
The tracked contents of this directory are currently limited to this `README.md` boundary note. No current BOM, Gerber archive, NC-drill archive, pick-and-place export, or assembly package is tracked here.

The repository intentionally delays supplying push-button manufacturing `.zip` drops until the prototype layout and bring-up findings have completed release-level hardware checks. Consequently, the distributed hardware asset constitutes a **reference bundle**: useful for code review, schematic tracing, bench validation, and planning, but not a factory-ready fabrication package.

When a verified revision is confirmed, standardized manufacturing artifacts should be added here with explicit version and validation notes.
